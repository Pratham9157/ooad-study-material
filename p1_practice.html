Section A · Definitions & Short Answers (2–3 marks)

A1 · Define a token. List the types of tokens in C++.
Show Answer

A token is the smallest individual unit of a program that is meaningful to the compiler. C++ tokens: keywords (int, class), identifiers (total, main), literals/constants (10, 'a', "hi"), operators (+, <<, &&), and punctuators/separators (;, {}, (), ,).

A2 · What is the difference between a declaration and a definition of a function?
Show Answer
  • Declaration (prototype) tells the compiler the function's name, return type and parameter types, e.g. int add(int, int);. No body; ends with ;. Can appear many times.
  • Definition provides the body — the actual code, e.g. int add(int a, int b) { return a + b; }. Exactly one definition per function in a program (One Definition Rule).

A4 · What is procedural abstraction? Why are preconditions and postconditions written?
Show Answer

Procedural abstraction means treating a function as a black box: users know what the function does (through its name, prototype and comment), not how it does it. The implementation can be changed without affecting callers. Precondition states what must be true before the call (valid inputs); postcondition states what will be true after the call (the result/effect). They document the contract between the function and its caller.

A5 · Define function overloading. Can two functions be overloaded on return type only?
Show Answer

Function overloading is defining multiple functions with the same name but different parameter lists (number, type, or order of parameters) in the same scope; the compiler selects the right one at compile time (static polymorphism). No — functions differing only in return type cannot be overloaded, because the call f(); gives the compiler no way to choose. It is a compile error.

A7 · What is recursion? What are the two essential parts of a recursive function?
Show Answer

Recursion is a technique where a function calls itself (directly or indirectly) to solve a problem by reducing it to smaller instances of the same problem. Essential parts: (1) Base case – solved directly without recursion; stops recursion. (2) Recursive case – calls itself with a smaller/simpler argument that progresses towards the base case. Without a base case → infinite recursion → stack overflow.

A8 · What is the difference between a local variable and a static local variable?
Show Answer

Both have block scope (visible only inside the function). A normal local variable is created on every call and destroyed on return (value lost, initial value garbage). A static local variable is initialized only once, lives for the entire program, and retains its value between calls (default initial value 0).

A9 · Differentiate between a pointer and a reference (any four points).
Show Answer
  1. A reference must be initialized when declared; a pointer need not be.
  2. A reference cannot be re-seated to another variable; a pointer can be changed to point elsewhere.
  3. A reference cannot be null; a pointer can be nullptr.
  4. A reference is used directly (r = 5); a pointer needs dereferencing (*p = 5).
  5. Pointer arithmetic is possible; there is no reference arithmetic.
A10 · What are default arguments? State the rules.
Show Answer

Default arguments are values specified in a function declaration that are used automatically when the caller omits the corresponding arguments, e.g. void f(int a, int b = 10);. Rules: (1) defaults must be assigned from right to left – only trailing parameters can have defaults; (2) specify them only once (usually in the prototype); (3) arguments can be omitted only from the right in a call; (4) they can create ambiguity with overloaded functions.

D2 · Why does this not compile? Fix it.
C++
#include <iostream>
using namespace std;
int sum(int a = 5, int b);
int main() { cout << sum(3); return 0; }
int sum(int a, int b) { return a + b; }

D3 · Identify the error.
C++
#include <iostream>
using namespace std;

double area(int s) { return 3.14 * s * s; }

D4 · Identify the logical error.
C++

        i++;

{

Show Answer

6

Section F · Long Answer (5–8 marks)

F1 · Explain the different ways of passing parameters to functions in C++ with a single program that demonstrates all three. State when each should be used.
Show Answer

Three ways: call by value, call by reference, call by address (pointer) — see Lesson 2.4 for the full swap program and comparison table. Write the swap program with all three functions, show the output (1 2 / 2 1 / 1 2), and conclude:

  • Value – when the function must not change the argument and the data is small (e.g. int).
  • Reference – when the function must change the caller's variable(s) or return several values; const & for passing large objects efficiently without allowing change.
  • Pointer – when "no object" (nullptr) is a valid possibility, when working with dynamic memory/arrays, or for C-compatibility.
F2 · What is top-down design? Illustrate with a program that computes simple statistics (sum, average, maximum) of 5 numbers using separate functions.
Show Answer

Top-down design (stepwise refinement): start with the overall task, break it into sub-tasks, refine each sub-task further until each is simple enough to code as one function. main() then just calls these functions — the program structure mirrors the problem structure. Benefits: modularity, reuse, easy testing, readability, team work.

Statistics
├── readData
├── computeSum   ──► used by computeAverage
├── computeAverage
├── findMax
└── report
C++
#include <iostream>
using namespace std;

void readData(int a[], int n)
{
    int sample[5] = {12, 45, 7, 30, 18};   // in an exam you'd use cin
    for (int i = 0; i < n; i++) a[i] = sample[i];
}
int computeSum(const int a[], int n)
{
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
double computeAverage(const int a[], int n)
{
    return static_cast<double>(computeSum(a, n)) / n;   // function calling function
}
int findMax(const int a[], int n)
{
    int m = a[0];
    for (int i = 1; i < n; i++) if (a[i] > m) m = a[i];
    return m;
}
void report(const int a[], int n)
{
    cout << "Sum = " << computeSum(a, n) << endl;
    cout << "Average = " << computeAverage(a, n) << endl;
    cout << "Max = " << findMax(a, n) << endl;
}
int main()
{
    int data[5];
    readData(data, 5);
    report(data, 5);
    return 0;

#include <iostream>

int sumRec(int n)
{
    if (n == 0) return 0;          // base case
    return n + sumRec(n - 1);      // recursive case
}

int sumIter(int n)
{
    int s = 0;
    for (int i = 1; i <= n; i++) s += i;
    return s;
}
