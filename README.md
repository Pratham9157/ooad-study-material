# OOAD Study Material

A static, lesson-by-lesson study site for an Object-Oriented Analysis & Design course:
C++ foundations, OOP, UML, GRASP and GoF design patterns. Every C++ example is compiled
and run by the validator, and its output is checked against the documented output.

## Layout

```
content/
  course.json        course outline: chapters, lesson slugs, titles, syllabus mapping
  lessons/           one Markdown file per lesson (plus index.md for the home page)
  diagrams/          SVG diagrams, inlined into lessons with <<SVG:name>>
tools/
  ooad.py            command-line entry point (export | check)
  ooadsite/          Markdown renderer, lesson exporter, C++ validator
web/                 React + TypeScript app (Vite)
  src/components/    Layout (persistent shell), Sidebar, Home, LessonPage
  src/data/          lessons.json, generated by `tools/ooad.py export` (not committed)
```

## Usage

Requires Python 3.10+ (standard library only) and Node 18+.

```bash
python tools/ooad.py export         # render lessons to web/src/data/lessons.json
cd web && npm ci && npm run dev     # local dev server at http://localhost:5173
cd web && npm run build             # typecheck + production build into web/dist/
python tools/ooad.py check          # compile and run all C++ examples (needs g++)
python tools/ooad.py check 05_      # only lessons whose file name contains "05_"
```

The validator looks for `g++` on `PATH`. Set `OOAD_GXX` to a full compiler path to override.

## Writing a lesson

1. Add the lesson's slug, title and syllabus tag to `content/course.json`.
2. Create `content/lessons/<slug>.md`. Use the Markdown dialect documented in `tools/ooadsite/markdown.py`.
3. Run `python tools/ooad.py export`, then check the page in `npm run dev`.
4. Run `python tools/ooad.py check <slug>` if the lesson contains C++.

## Deployment

Vercel runs the export, then builds the React app, and serves `web/dist/` (see `vercel.json`).
All routes rewrite to `index.html`, so lesson URLs are client-side routes such as `/14_6_strategy`.
